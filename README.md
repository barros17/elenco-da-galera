# Elenco da Galera

App da pelada: cadastro de jogadores, cartas estilo FIFA Ultimate Team e sorteio de times equilibrados.

- Interface 100% em português do Brasil, mobile-first (preto, amarelo, cinza e branco)
- Cartas por faixa de overall: Bronze (<65), Prata (65–74), Ouro (75–84), Diamante (85+)
- Fotos de jogador com enquadramento no navegador (quadrado 512px, PNG transparente)
- Sorteio equilibrado: serpentina + hill climbing, máx. 1 goleiro por time
- Sem login: cada navegador tem seu próprio conjunto de jogadores

## Rodar localmente

```bash
npm install
npm run dev
```
